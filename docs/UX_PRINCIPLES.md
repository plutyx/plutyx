# UX principles

1. Mobile first, one-hand actions where possible.
2. Dashboard answers “what needs attention now?” before showing charts.
3. Hide complexity by role and preference, never by deleting underlying data.
4. KDS uses status columns and large tap targets; no dedicated hardware required.
5. Inventory shows actionable stock/par/reorder numbers, not ERP terminology.
6. Demand forecast always exposes confidence and historical basis.
7. Financial screens use contribution language; never imply guaranteed profit.
8. Empty states teach the next useful action.
9. Personalization is per member, so production and finance can have different workspaces.
10. Paid integrations are optional enhancements, not prerequisites for core operation.
