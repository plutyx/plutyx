# Cozinha 360 OS

SaaS/PWA para microempreendedores e pequenos negócios de alimentação. O produto transforma o método Cozinha de Bolso 360 em um sistema operacional simples: custos, precificação, capacidade, pedidos, recompra e decisões diárias.

> Status: implementação cloud-first em andamento. Nunca declarar conformidade sanitária/legal automaticamente e nunca garantir lucro.
